# Stats Analyzer

Приложение для анализа статистических данных с графическим интерфейсом.

## Участники команды

| Участник | Аккаунт | Вариант | Ветка |
|----------|---------|---------|-------|
| Александр | rultted | Вариант 3 — Погода | feature/weather |
| Сантьяго | SantiagoSun | Вариант 2 — Курс валют | feature/currency |

## Структура проекта
stats-analyzer/
├── main.py             # Точка входа
├── data/
│   ├── weather.json    # Данные о погоде
│   └── currency.json   # Данные о курсе валют
├── ui/
│   ├── main_window.py  # Главное окно
│   ├── weather_tab.py  # Вкладка погоды
│   └── currency_tab.py # Вкладка валют
└── utils/
├── data_loader.py  # Загрузка данных
└── forecaster.py   # Прогнозирование
## Модули

### Вариант 3 — Анализ погоды (rultted)
- Загрузка данных о температуре из JSON файла
- Таблица с данными за месяц (мин температура синим, макс красным)
- Графики максимальной, минимальной и средней температуры
- Статистика перепадов температуры
- Прогнозирование методом скользящей средней на N дней
- Экспорт графика в PNG/PDF/SVG

### Вариант 2 — Анализ курса валют (SantiagoSun)
- Загрузка данных о курсе USD и EUR из JSON файла
- Таблица с курсами за месяц
- Графики курса рубля к двум валютам
- Статистика максимальных и минимальных значений курса
- Прогнозирование методом скользящей средней на N дней
- Экспорт графика в PNG/PDF/SVG

## Технологии

- **Python 3.14**
- **PyQt6** — графический интерфейс
- **Matplotlib** — графики
- **Pandas** — обработка данных

## Структура веток

- `main` — финальная версия релиза
- `dev` — ветка разработки, слияние модулей
- `feature/weather` — модуль погоды (rultted)
- `feature/currency` — модуль валют (SantiagoSun)
